# Как запустить бота 24/7 без своего ПК

## Бесплатно: Bothost + база Neon (без банковской карты)

- **Bothost** (bothost.ru) — бесплатный тариф для одного бота, работает 24/7, карта не нужна.
  Но на бесплатном тарифе диск **стирается при перезапуске**, поэтому сохранения игроков храним отдельно.
- **Neon** (neon.tech) — бесплатная облачная база Postgres. Бот сам создаст в ней таблицу и будет
  хранить там прогресс всех игроков.

### Шаг 1. База Neon (≈3 мин)
1. Зарегистрируйтесь на https://neon.tech (можно через Google или GitHub), выберите бесплатный план (Free).
2. Создайте проект (любое имя, регион — Европа, например Frankfurt).
3. На главной странице проекта нажмите **Connect** и скопируйте строку подключения.
   Она выглядит так: `postgresql://user:пароль@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. В папке проекта создайте файл **database_url.txt** и вставьте туда эту строку (одна строка, ничего лишнего).

### Шаг 2. Собрать архив
В папке проекта откройте PowerShell и выполните:
```
Compress-Archive -Force -Path bot.py, engine.py, requirements.txt, database_url.txt -DestinationPath bot.zip
```
Получится `bot.zip`. (`token.txt` класть не нужно — токен вводится на сайте.)

### Шаг 3. Bothost (≈3 мин)
1. Зарегистрируйтесь на https://bothost.ru и выберите бесплатный тариф **Starter**.
2. Создайте бота: язык **Python**, в поле **Bot Token** вставьте токен от @BotFather.
3. Загрузите `bot.zip` (способ «загрузить архив»). Если спросят команду запуска — `python bot.py`.
4. Запустите бота и откройте логи. Должны быть строки
   `Сохранения хранятся в базе данных` и `Бот запущен`.

**Перед запуском остановите бота у себя на ПК** — иначе Telegram выдаст ошибку `Conflict`.

### Обновление игры
Поменяли `engine.py`/`bot.py` → снова соберите `bot.zip` (шаг 2), загрузите его в Bothost и перезапустите бота.
Прогресс игроков в базе при этом не пропадает.

### Ограничения бесплатного варианта
- 256 МБ памяти, один бот — для этой игры хватает с запасом.
- Бесплатные тарифы могут менять условия; если Bothost перестанет подходить, тот же `bot.zip`
  и та же база Neon подойдут для любого другого хостинга или VPS (см. ниже).
- Локально (без `database_url.txt`) бот, как и раньше, хранит сохранения в папке `saves/`.
  Старые сохранения из `saves/` автоматически в базу не переносятся.

## Вариант А — свой VPS (надёжно, ~150–300 ₽/мес)

Подойдёт любой самый дешёвый Linux-сервер (Ubuntu 22/24, 1 ядро, 512 МБ–1 ГБ RAM):
Timeweb Cloud, Aeza, Beget, Selectel, Hetzner и т.п. Сохранения игроков лежат прямо на диске сервера — ничего не теряется.

### 1. Залить файлы на сервер
На своём ПК, в папке проекта (PowerShell):
```
ssh root@IP_СЕРВЕРА "mkdir -p /opt/rayony"
scp bot.py engine.py requirements.txt token.txt rayony-bot.service root@IP_СЕРВЕРА:/opt/rayony/
```
(Если хотите перенести текущие сохранения игроков — `scp -r saves root@IP_СЕРВЕРА:/opt/rayony/`.)

### 2. Установить и запустить (на сервере)
```
ssh root@IP_СЕРВЕРА
apt update && apt install -y python3 python3-venv
cd /opt/rayony
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp rayony-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now rayony-bot
```
Всё. Бот работает круглосуточно и сам перезапускается после падения или перезагрузки сервера.

### Полезные команды
- `systemctl status rayony-bot` — работает ли
- `journalctl -u rayony-bot -f` — логи в реальном времени
- `systemctl restart rayony-bot` — перезапуск после обновления `bot.py`/`engine.py` (сначала залить их заново через `scp`)

**Важно:** не запускайте бота одновременно на ПК и на сервере — Telegram выдаст ошибку `Conflict`.

## Вариант Б — облачная платформа с Docker (без настройки сервера)

В проекте есть `Dockerfile`. Подойдёт любой хостинг, который умеет запускать Docker-контейнер
как фоновый процесс (worker) и даёт постоянный диск: Railway, Fly.io, Amvera, Timeweb Apps и др.

1. Загрузите проект на GitHub (**без** `token.txt` и `gemini.txt` — они не должны попасть в интернет).
2. Создайте на платформе новый сервис из этого репозитория — она соберёт `Dockerfile` сама.
3. Добавьте переменную окружения `BOT_TOKEN` = ваш токен от BotFather.
4. Подключите постоянный диск (Volume) к пути `/data` — иначе при каждом перезапуске
   прогресс игроков будет теряться.
5. Бот не открывает HTTP-порт, поэтому тип сервиса — **Worker / Background**, а не Web.

Бесплатные «веб-сервисы», которые засыпают без трафика (Render Free и подобные), для этого бота не подходят.
