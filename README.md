# «Районы и магазины» — Telegram-бот

## Запуск (Windows, ~5 минут)

1. Установите Python 3.10 или новее с python.org. При установке поставьте галочку **Add Python to PATH**.
2. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя и получите **токен** — строку вида `123456:ABC...`.
3. Распакуйте архив в любую папку и создайте рядом с `bot.py` файл **token.txt**, вставив в него токен.
4. Откройте в этой папке командную строку (в адресной строке Проводника наберите `cmd` и нажмите Enter) и выполните:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
5. Найдите своего бота в Telegram и нажмите **Start**.

Бот работает, пока открыто окно с `python bot.py` и компьютер не спит. Чтобы бот работал круглосуточно, его нужно запустить на VPS — там всё делается так же.

## Файлы
- `engine.py` — вся игра: время, счётчики, локации, драки, полиция, финалы. От Telegram не зависит.
- `bot.py` — Telegram-обвязка (aiogram 3): кнопки, сохранения в папке `saves/`.
- `play_console.py` — та же игра в консоли, без Telegram: `python play_console.py`.

## Команды бота
`/start` — продолжить игру, `/new` — начать заново, `/help` — подсказки.
